3. สิ่งที่รวม / ไม่รวม

รวมในทุกแพ็ก

  • Hosting เว็บ + ฐานข้อมูล
  • อัปเดต catalog สกิน
  • แก้ bug ระบบหลัก
  • SSL / HTTPS
  • สำรองข้อมูล user และประวัติ

ไม่รวม (คิดเพิ่ม)

  • ต่อ PromptPay / TrueMoney / Stripe — ฿15,000–30,000
  • ฟีเจอร์ใหม่ / UI ใหม่ — ฿1,200/ชม.
  • เกมใหม่นอก 3 เกม — ตาม scope
  • ค่าโดเมน — ลูกค้าจ่ายตรงหรือคืนใบเสร็จ

5. สิทธิ์และ Timeline

  • Source code เป็นทรัพย์สินของผู้ให้บริการ — ไม่มีการโอน source code
  • แบรนด์ โดเมน และข้อมูลลูกค้า เป็นของลูกค้า
  • เมื่อสิ้นสุดสัญญา — ขอ export ข้อมูล user ได้
  • Timeline: confirm + มัดจำ → ตั้งค่า 5–10 วัน → launch รวมประมาณ 7–14 วันทำการ

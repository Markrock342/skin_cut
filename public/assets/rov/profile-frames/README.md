# RoV profile frames (PNG / WebP)

ไฟล์ต้องตรงกับ `id` ใน `src/data/rov/profile-frames.ts`

- ตัวอย่าง: `rank-s12.png` หรือ `rank-s12.webp` = กรอบแรงค์ซีซัน 12
- กิจกรรม: `evt-aic.png`, `evt-rpl-summer.png`, …

โฟลเดอร์นี้ว่างได้ — ถ้าไม่มีรูป แอปจะใช้กรอบวงแหวน CSS ชั่วคราว

รูปแนะนำ: PNG โปร่ง (กลางโปร่ง ขอบทับช่องสกิน) สัดส่วนใกล้กับช่องสกินในโปสเตอร์ (ประมาณ 3:4 ของช่อง)
